# Residential Lighting System Design

A residential lighting system design project that includes illumination calculations, luminaire selection, electrical load analysis, voltage drop calculations, and cost estimation for two different house designs.

## Overview

This project presents two alternative residential lighting designs developed by applying lighting engineering principles. Each design includes room-by-room illumination calculations, fixture selection, electrical loading analysis, and material cost estimation.

## Features

- Residential lighting design
- Indoor and outdoor illumination planning
- Luminous flux calculations
- Lux level calculations
- Luminaire selection
- Electrical load analysis
- Voltage drop calculations
- Cable sizing
- Distribution board loading
- Material quantity estimation
- Project cost analysis
